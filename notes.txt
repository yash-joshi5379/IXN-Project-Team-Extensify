            gripper itself. May influence position values 

Episode 26: The gripper comes into contact with the target causing the 
            box and socket to move slightly 

Episode 29: The first grasp clutch attempt was unsuccessful

Episode 34: After grabbing the object, the arm reaches the target a
            first time, swings violently off the target, then reaches
            the target a second time before dropping the object into
            the target

Episode 36: After grasping the object and reaching the target, the
            gripper came in close contact with the target, which 
            caused the object to shift slightly, hence the arm moved 
            away from the target and readjusted before approaching 
            again and dropping the object into the target

Episode 40: Arm takes a long time to reach initial object

Episode 41: Arm starts very far from object so takes longer to reach
            initial object
